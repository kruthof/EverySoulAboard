# PERILUNE

A colony simulation aboard the drifting ship **MSV Perilune** — Dwarf-Fortress-deep
systems, 2D presentation aiming decisively past RimWorld's fidelity, and a crew of
people you can actually talk to:
LLM-performed, simulation-adjudicated, remembered forever in the ship's chronicle.

## Quick start

```bash
./play.sh                                                   # PLAY — the whole game, one command
./ci.sh                                                     # full gate (dotnet + node)
~/.dotnet/dotnet run --project hosts/tui -- --play          # terminal skin
~/.dotnet/dotnet run --project hosts/scenario -- --days 3 --seed 42   # determinism proof
```

`./play.sh` starts the sim host and the client's static server, waits for both, prints one
URL and opens it; Ctrl+C stops both. There is no ship to pick — `hosts/web` serves
`--ship grid`, the one standard surface. `--ship slice` and `--ship perilune` are **test
fixtures** (the headless economy measurement fixture and the determinism-golden ship);
they are not games and `play.sh` does not offer them.

No Unity, no engine install — the entire game truth runs headless on .NET 8; the
browser client is a skin over a semantic wire protocol. AI sprite art is generated by
`art/spritegen/` (Gemini image API).
