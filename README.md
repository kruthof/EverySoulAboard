# PERILUNE

A colony simulation aboard the drifting ship **MSV Perilune** — Dwarf-Fortress-deep
systems, RimWorld-grade presentation, and a crew of people you can actually talk to:
LLM-performed, simulation-adjudicated, remembered forever in the ship's chronicle.

- **Vision & differentiation:** [docs/VISION.md](docs/VISION.md)
- **Architecture:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- **Implementation plan (parallel workstreams):** [docs/PLAN.md](docs/PLAN.md)

## Quick start

```bash
~/.dotnet/dotnet test tests/Perilune.Tests --nologo         # full headless suite
~/.dotnet/dotnet run --project hosts/web                    # play: http://localhost:8323
~/.dotnet/dotnet run --project hosts/tui -- --play          # terminal skin
~/.dotnet/dotnet run --project hosts/scenario -- --days 3 --seed 42   # determinism proof
```

No Unity, no engine install — the entire game truth runs headless on .NET 8; the
browser client is a skin over a semantic wire protocol. AI sprite art is generated by
`art/spritegen/` (Gemini image API).
